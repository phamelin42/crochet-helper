## 4. Parseur : proposition de corpus doré scoré

extraits ; les 5 patrons réels de `fixtures/` ne sont lus **par aucune spec**
(seul `tools/dump-fixtures.mts` les affiche, à l'œil).

**Proposition** (non implémentée) :

- `fixtures/<nom>.expected.json` à côté de chaque `.txt` : titre, lignes de
  matériel, nombre de pièces, libellés d'étapes attendus — écrits à la main,
  une fois, en lisant le patron (jamais générés par le parseur, sinon le
  corpus fige ses bugs) ;
- `tools/score-parser.mjs` : pour chaque fixture, score = moyenne de
  titre exact (0/1), rappel du matériel, rappel des libellés d'étapes,

  échoue si un score descend ; une fiche qui l'améliore relève le plancher
  dans la même PR ;

  lectrice) devient une fixture. Les dix-neuf en-têtes de la fiche 18 en
  sont les premiers candidats (12/19 reconnus aujourd'hui).

**Effort** M (moitié : écrire les attendus). **Étape** : activation.

## 5. Préparation d'un empaquetage natif (Capacitor)

Le build statique (`outputMode: 'static'`, `dist/fil-patterns/browser`) est un
`webDir` valable. Ce qui bloquerait ou fausserait l'application native :

| Bloquant                                                                                 | Pourquoi                                                                                                  | Effort                                                         |
| ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Permalien construit sur `window.location.origin` (`pattern-import.ts:193`)               | dans l'app l'origine est `capacitor://localhost` : les liens partagés seraient morts                      | S — utiliser `SITE_ORIGIN`                                     |
| Service worker (`ngsw`)                                                                  | non pris en charge sur le schéma de l'app iOS ; inutile hors ligne dans une app qui embarque ses fichiers | S — ne pas l'enregistrer en natif                              |
| Téléchargement de sauvegarde par `<a download>` (`projects-page.ts:262`), presse-papiers | ne fonctionnent pas ou mal dans WKWebView                                                                 | M — passer par `core/platform`, puis greffons Filesystem/Share |
| Mesure limitée à `patternreader.com`                                                     | l'app a pour hôte `localhost` : aucune mesure                                                             | S — drapeau « natif » dans `ANALYTICS_HOSTNAMES`               |
| Verrou d'écran (`wake-lock.service.ts`)                                                  | `navigator.wakeLock` absent de WKWebView ancien                                                           | S — greffon ou repli                                           |
| Achat intégré imposé par Apple pour un déblocage                                         | une clé de licence web ne suffirait pas sur l'App Store                                                   | M — `EntitlementService` abstrait (clé ou achat intégré)       |
