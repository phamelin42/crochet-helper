# Diffusion — journal et plan

Aucune ligne de code n'amène une lectrice la semaine prochaine ; ces gestes,
si. Une heure, un canal par semaine, dans cet ordre. Le message est toujours le
même : un outil gratuit, sans compte, qui marche avec n'importe quel patron, et
une question honnête à la fin.

Chaque message posté prend une ligne dans le journal ci-dessous, pour que le
point hebdomadaire du pilote puisse rapprocher les pics de visites de leur
cause : Umami affiche la source (`referrer`), et la fiche 21 la conserve.
